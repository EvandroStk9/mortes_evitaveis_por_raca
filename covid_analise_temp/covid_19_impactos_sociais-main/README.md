# Impactos sociais da Covid-19 no Brasil
Este é um repositório para os scripts e outputs relacionados ao monitoramento dos impactos do Covid-19 que é desenvolvido pelo núcleo Afrodados do Afro Cebrap

Trata-se de um projeto desenvolvido em uma cooperação de profissionais de áreas de ciências sociais aplicadas que hoje é desenvolvido no Afrodados, mas que apreseenta uma continuidade de desenvolvimento ao longo da trajetória dos pesquisadores por diferentes ambientes institucionais.

Uma primeira versão de monitoramento que deu origem a este projeto foi feita pela equipe do Escritório de Desenvolvimento Social de Minas Gerais - EDS-Minas (antigo Observatório do Desenvolvimento Social - ODS Minas), vinculado à Secretaria de Estado de Desenvolvimento Social de Minas Gerais - SEDESE-MG, e está disponível em: <https://github.com/ods-minas/Covid-19>

Um produto relacionado, em uma parceria da equipe do ODS-Minas com os pesquisadores líderes Lívia Almeida e Ricardo Campante Vale, foi o painel de monitoramento da vacinação de Covid. Disponível em: <https://ods-minas.shinyapps.io/covid-19/>
